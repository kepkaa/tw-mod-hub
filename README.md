# Kepka Deck

_made with love by [kepkaa](https://github.com/kepkaa) ❤️_

Twitch-плеер, чат и модерация в одном окне.

## Скачать

**[⬇ Скачать Kepka-Deck-Setup.exe](https://github.com/kepkaa/tw-mod-hub/releases/latest/download/Kepka-Deck-Setup.exe)** (Windows)

1. Скачай и запусти файл — установка в один клик, без вопросов.
2. Открой приложение → **⚙ → Войти через Twitch** → разреши доступ.
3. Всё. Подписки, чат и права модератора определятся сами.

Ничего настраивать не нужно: Node.js, Client ID и прочее не требуются.
Новые версии скачиваются и ставятся сами при запуске приложения.

> Windows может показать «Windows защитила ваш компьютер» — установщик не подписан платным сертификатом.
> Нажми **Подробнее → Выполнить в любом случае**.

## Возможности
- 🎬 Плеер Twitch с индикатором задержки и авто-догоном эфира
- 💬 Собственный чат: удаление, мут и бан прямо из интерфейса, настоящие значки Twitch
- 🛡 Права модератора определяются автоматически. Нет прав — остаются только AHK-макросы
- 📊 Опросы и 🎯 ставки (на своём канале, нужен Affiliate/Partner)
- 💎 Баллы канала в шапке и авто-сбор бонуса
- ⌨ Глобальные хоткеи и экспорт AHK v2
- 🚫 Блокировка рекламы
- 📜 Личная база действий — у каждого пользователя своя
- 📱 Мобильная вёрстка (узкое окно)

## Настройки «под себя»
Все в приложении: **⚙ Настройки** (кнопка открывает и закрывает панель, Esc тоже закрывает).
Файлы пользователя лежат в `%APPDATA%\tw-mod-hub\` (настройки, база, `error.log`).

# Для разработчика

## Как выпустить новую версию
1. Внёс изменения в код.
2. Запусти **`publish.bat`** → введи номер версии (например `1.3.1`).
3. Через 3–5 минут GitHub сам соберёт установщик и выложит его в [Releases](https://github.com/kepkaa/tw-mod-hub/releases).
   Ссылка «Скачать» выше начнёт отдавать новую версию, а уже установленные копии обновятся сами.

Сборку видно во вкладке [Actions](https://github.com/kepkaa/tw-mod-hub/actions).
Токены и секреты настраивать не нужно — используется встроенный `GITHUB_TOKEN`.

## Запуск из исходников
```
npm install
npm start
```
Только собрать файл у себя, без публикации: `npm run dist` → папка `dist`.

## Админ-режим (для владельца)
1. Вкладка **👑 Админ** → задай пароль (мин. 6 символов).
2. Открывается редактор: **Объявление** (видят все) и **доп. правила блокировки рекламы** (по одному на строку, формат `*://*.example.com/*`).
3. Поле **remote-config.json URL**: raw-ссылка, например
   `https://raw.githubusercontent.com/kepkaa/tw-mod-hub/main/remote-config.json`
4. **Экспорт remote-config.json** → положи файл в репозиторий по этому адресу.
5. У всех пользователей приложение раз в час и при запуске подтягивает объявление и правила.

## Свой Client ID (необязательно)
В приложение зашит общий Client ID, пользователям ничего вводить не надо.
Если захочешь свой: https://dev.twitch.tv/console → Register Your Application, OAuth Redirect URL `http://localhost`.
