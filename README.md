# Kepka Deck

_made with love by [kepkaa](https://github.com/kepkaa) ❤️_

Twitch-плеер, чат и модерация в одном окне. Никаких Telegram/Discord/VPN.
Работает на Windows, macOS и Linux (Electron). Полностью адаптирован под телефон (узкое окно).

## Возможности
- 🎬 Плеер Twitch + собственный чат с IRC (delete/mute/ban прямо из интерфейса)
- 🛡 Автоопределение прав модератора: если ты не мод — панели модератора нет, остаются только AHK-макросы
- ⌨ Глобальные хоткеи + экспорт AHK v2
- 🚫 Блокировка рекламы (в т.ч. расширяемая через remote-config.json от администратора)
- 📜 Личная база действий (SQLite в `%APPDATA%\tw-mod-hub\modhub.sqlite`) — у каждого пользователя своя
- 👑 Админ-режим с объявлением и доп. правилами блокировки
- 📱 Мобильная вёрстка: нижняя навигация, action-sheet для действий с сообщением

## Запуск
1. Node.js → https://nodejs.org
2. `npm install`
3. `npm start`

## Первая настройка Twitch
1. https://dev.twitch.tv/console → Register Your Application
   - OAuth Redirect URL: `http://localhost`
   - Category: Application Integration
2. Скопируй Client ID → в приложении вкладка **⚙ Настройки** → вставь → **Войти**.
3. Готово: подписки подгрузятся, чат подключится автоматически.

## Где настраивать «под себя»?
**Всё в приложении, в правой панели** — вкладка **⚙ Настройки**:
- Client ID / вход
- Акцент, анимация, компактный режим
- Автообновление списка стримов
- Блокировка рекламы (вкл/выкл)

Файлы настроек — в `%APPDATA%\tw-mod-hub\`:
- `settings.json` — твои настройки (у каждого пользователя свой)
- `modhub.sqlite` — журнал действий (у каждого свой)
- `admin-config.json` — только для админа
- `error.log` — диагностика

Кнопка **Открыть папку настроек** — в той же вкладке.

## Как узнать, что я не мод?
Если на текущем канале у тебя нет прав модератора:
- правый блок «🛡 Мод» исчезает
- остаётся вкладка **⌨ Макросы** (работает всегда)
- в чате нельзя удалять чужие сообщения (только собственные через Twitch API)
- история действий пишется только твоя

## Удаление сообщений (в т.ч. на телефоне)
- **Десктоп:** наведи на сообщение → кнопка **✕**
- **Телефон:** нажми на сообщение → откроется шит с «Удалить / Таймаут / Бан / Ответить».

Работает только если ты модератор на канале.

## Админ-режим (для тебя, владельца)
1. Открой вкладку **👑 Админ**.
2. Задай пароль (мин. 6 символов) → **Задать пароль**. Он сохранится в `settings.json` (hash + salt).
3. После этого откроется редактор:
   - **Объявление** — показывается всем пользователям (из твоего remote-config.json)
   - **Доп. правила блокировки рекламы** — по одному на строку, формата `*://*.example.com/*`
4. Заполни поле **remote-config.json URL** (например, raw-ссылка на GitHub):
   `https://raw.githubusercontent.com/твой-логин/твой-репозиторий/main/remote-config.json`
5. Нажми **Экспорт remote-config.json** → положи файл в свой репозиторий по этому URL.
6. Теперь **у всех пользователей** приложение раз в час (и при запуске) подтягивает объявление и правила блокировки. Плюс кнопка **Подтянуть сейчас**.

Пароль хранится только локально; после перезапуска нужно снова **Разблокировать**.

## Сборка и публикация

Иконка (`build/icon.png`, `build/icon.ico`) рисуется скриптом `make-icon.js` автоматически перед запуском и сборкой.

1. **Код на GitHub:** создай пустой репозиторий `tw-mod-hub` на https://github.com/new → запусти `push.bat`.
2. **Токен:** https://github.com/settings/tokens → Generate (classic) → галка `repo` → `setx GH_TOKEN токен`, открой новое окно консоли.
3. **Релиз:** подними `version` в `package.json` → `release.bat`. Установщик появится в Releases, у уже установленных копий обновление придёт само.
4. Только собрать файл без публикации: `npm run dist` → папка `dist`.
