# Kepkaa Deck

Программа для Windows: стрим Twitch, чат и модерация в одном окне.

## Скачать

[**Kepkaa-Deck-Setup.exe**](https://github.com/kepkaa/tw-mod-hub/releases/latest/download/Kepkaa-Deck-Setup.exe)

Запусти файл — программа поставится сама и откроется. Дальше нажми «Войти через Twitch» и разреши доступ. Больше ничего настраивать не нужно. Новые версии ставятся автоматически.

Windows при первом запуске может написать «Windows защитила ваш компьютер» — у установщика нет платной подписи. Нажми «Подробнее» → «Выполнить в любом случае».

## Что умеет

- смотреть стримы из своих подписок и открывать любой канал по нику
- читать чат и писать в него; значки, как на Twitch
- если ты модератор: удалять сообщения, мутить, банить и разбанивать, а на своём канале ещё запускать опросы и ставки
- если ты не модератор, лишнего не показывает: остаются стрим, чат и макросы
- макросы на горячих клавишах, можно выгрузить в AutoHotkey
- видеть баллы канала и автоматически собирать бонус
- блокировать рекламные запросы
- ведёт личный журнал действий, он хранится только у тебя на компьютере

## Телефон

Окно можно сузить — интерфейс перестраивается под телефон, а сообщение в чате удаляется или мутится нажатием на него.
